# Security policy

## Supported versions

Only the [latest release](https://github.com/shayhenderson/skaldic/releases/latest) receives security fixes. The app offers updates when it starts, so staying current is one click.

## Reporting a vulnerability

Please report vulnerabilities privately, through this repository's **Security** tab: choose **Report a vulnerability** (GitHub private vulnerability reporting). Do not open a public issue or discussion for a security problem.

Helpful details: the Skaldic version, what you found, steps or a file that reproduces it, and the impact you expect.

You can expect a first response within 7 days. Once a fix is released, the report can be credited to you if you'd like.

There is no bug bounty.

## Verifying downloads

Releases from v0.2.0 on are signed with the project's updater key. See [Verifying a download](README.md#verifying-a-download) in the README.
